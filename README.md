# **Installation Instructions**
## *Requirements*
### 1. Github Account 
### 2. Github Desktop
### 3. Visual Studio Code
## *Installation*
### 1. On the page you are currently at, in the top right corner, there should be a button called [Fork] underneath the [Settings] button
### 2. Once clicked, it should bring you to a new page. Though you can do whatever you want here, nothing is necessary to run the program, just scroll down and click [Create Fork]
### 3. Now that you've forked the repository, open Github Desktop, click the [Add] button, then click [Clone a Repository]. This will then give you a list of repositories, scroll down until you reach the name of the repository you forked. Click on it to clone the repo in preperation for the next instructions...

# **How to use the 'Enlistment Data Interface'**
## *Opening the Program*
### 1. Once you've cloned the repository and opened it to VSC through Github, click on the folder [Main], then click on the python file [main.py]
### 2. Once on the file run the code, this will then take you to the actual interface
## *Using the Program*
### 3. When running the program, it should ask you for a username. This username can/may be anything whatsoever, due to it not actually being saved into the program files. (This will not affect the program whatsoever other than creating a more personalised experience)
### 4. Once your UID is entered, the actual interface will open up. Within the interface are 5 options; shown below:
1. View Raw Data
2. View Data Visualisation: How people see Enlistment (1-10)
3. View Data Visualisation: Main reason people would Enlist
4. View Averages
5. Exit Program
### 5. Type in a number corresponding to one of the options given in order to view the data within; options explained below:
1. Dataset of all Survey outcomes in a pandas dataframe
2. A choice of 2 types of charts (pie and bar) that both display how the responders see enlistment on a scale of 1-10
3. A choice of 2 types of charts (pie and bar) that both display the main reason why people would enlist (Housing, Employment, Education, Civil Duty)
4. Averages for each outcome from the data set. These averages show the mean score across all responses /5
5. When this option is selected the program will shut down, meaning all information you've inputted will be deleted, ensuring data safety
### NOTE: When choosing options within the main program or sub-programs, make sure you type in the number corresponding with the information you wish to view. Do not type in the option. If you do make a mistake and type an invalid input however, worry not! The program will take you right back to the data interface.
